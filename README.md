# tp-programacion-utn

PROGRAMACION IV

TIENDA DE ROPA CLAUDIA

El objetivo del trabajo de este cuatrimestre es crear una pagina de ropa la cual permita a nuestra querida cliente claudette posicionarse frente a sus posibles clientes y competidores de una manera distinto a la cual la venia haciendo. La pagina constara de un manejo de catalago-stock el cual el cliente podrá realizar de manera autónoma y a su gusto. También formulara una base de datos de todos los clientes que le compren, el cual le permitirá seguir haciendo seguimiento.
